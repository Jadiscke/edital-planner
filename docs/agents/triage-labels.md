# Triage Labels

| Papel canônico    | Rótulo no projeto | Significado                           |
| ---------------- | ----------------- | ------------------------------------- |
| `needs-triage`    | `needs-triage`    | Precisa de avaliação do mantenedor    |
| `needs-info`      | `needs-info`      | Aguarda informações do solicitante    |
| `ready-for-agent` | `ready-for-agent` | Especificada e pronta para agente AFK |
| `ready-for-human` | `ready-for-human` | Exige implementação ou decisão humana |
| `wontfix`         | `wontfix`         | Não será executada                    |

Quando uma skill mencionar um papel de triagem, usar o rótulo correspondente desta tabela.
