# Arquivar e duplicar projeto preservando isolamento

## Parent

[`../PRD.md`](../PRD.md)

## What to build

Permitir que o candidato arquive um projeto sem apagar seu histórico e crie uma duplicata independente com origem rastreável. A ação deve atravessar interface, API, domínio, banco e auditoria.

## Acceptance criteria

- [ ] Arquivar remove o projeto das listas ativas e o mantém consultável na área de arquivados.
- [ ] Duplicar cria um novo projeto ativo com identificador próprio e referência auditável à origem.
- [ ] Alterações futuras na duplicata não modificam o projeto original.
- [ ] Usuários de outro tenant não conseguem arquivar nem duplicar o projeto.
- [ ] Testes de integração e Playwright comprovam os comportamentos usando banco real e interfaces públicas.

## Agent Brief

**Category:** enhancement

**Summary:** adicionar arquivamento reversível de projetos e duplicação independente com origem auditável.

**Current behavior:** projetos ativos podem ser criados e recuperados, mas não existe separação entre listas ativa e arquivada nem uma operação de cópia rastreável.

**Desired behavior:** o candidato deve arquivar um projeto sem apagar seu histórico, consultar os arquivados e duplicar um projeto em uma nova identidade ativa. A duplicata preserva referência à origem no momento da cópia, mas evolui de forma independente. Todas as operações continuam isoladas por tenant e deixam evidência auditável.

**Key interfaces:**

- ciclo de vida de `Project` — representar estado ativo/arquivado sem exclusão destrutiva;
- operação de duplicação — produzir nova identidade e referência imutável à origem;
- consultas de projetos — separar ativos e arquivados de forma explícita;
- comandos HTTP e interface — expor arquivamento, consulta e duplicação com estados acessíveis;
- persistência e auditoria — aplicar isolamento por tenant e registrar as operações.

**Acceptance criteria:**

- [ ] Arquivar retira o projeto das listas ativas sem apagar dados ou histórico.
- [ ] A área de arquivados permite consultar o projeto arquivado.
- [ ] Duplicar cria um projeto ativo com ID próprio e referência auditável à origem.
- [ ] Mudanças posteriores na duplicata não alteram o original e vice-versa.
- [ ] Tentativas entre tenants são ocultadas ou rejeitadas segundo o contrato de autorização existente.
- [ ] Testes de domínio, contrato, PostgreSQL real e Playwright comprovam o fluxo pelas interfaces públicas.

**Out of scope:** exclusão definitiva, restauração de backups, cópia de documentos ainda não definida pelo produto e mudanças em processamento ou inferência de IA.
